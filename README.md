# US Large-Cap Pullback A/B Scoring Tool (Python)

Python-based decision support tool for **systematic pullback analysis** on US large-cap stocks.  
This tool is designed to help decide **when NOT to enter**, based on rule-based logic — not predictions or signals.

---

## What this tool does

- Evaluates pullback conditions on US large-cap stocks
- Classifies setups into **A / B quality** based on predefined rules
- Focuses on **risk filtering**, not entry signals
- Outputs simple, interpretable scores for decision support

---

## What this tool is NOT

- ❌ Not a trading bot  
- ❌ Not financial advice  
- ❌ Not a signal service  

This is a **logic-based filter** intended for experienced traders who already have execution rules.

---

## Intended users

- Traders using systematic or rule-based strategies
- Quant-minded discretionary traders
- Users who want to reduce low-quality entries
